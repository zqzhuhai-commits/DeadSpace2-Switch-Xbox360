# Switch 死亡空间2 xbox360版 汉化工具 v0.4 正式版

用户已确认实机测试通过，现将现有 v0.4 工具包正式发布。

## 下载内容

- **DS2_Localization_Tool_v04.zip**：Windows 64 位汉化工具，包含 EXE、源码、6894 条译稿、四套中文字库、合并资源、说明和报告。普通使用者下载此包即可。
- **DS2_Chinese_Translation_Final.zip**：原始最终翻译资源工程，供校对和研究；单独使用不能直接覆盖 VIV。v0.4 已包含术语统一后的资源，安装时使用工具包，不混搭两个版本。
- **SHA256SUMS.txt**：上述两个 ZIP 的 SHA-256 校验值。
- **RELEASE_NOTES.md**：本发布说明。
- GitHub 自动提供的 Source code 压缩包：本版本完整仓库工程和操作步骤。

## 功能

- 接入已提供语言文件的全部 6894 条索引，空译文为 0。
- 四套中文字库，变长资源合并及 VIV 索引更新。
- 自动备份原文件并安装，提供恢复方法。
- Disc 1、Disc 2 分别处理各自的完整 bigfile0.viv。

## 使用步骤

1. 解压工具包，在 Windows 64 位运行“Switch 死亡空间2 xbox360版 汉化工具.exe”。
2. 选择对应盘的完整 bigfile0.viv，选择尚不存在的输出路径。
3. 保持“自动备份并安装”勾选，输入和输出放在同一磁盘，预留一整份 VIV 加约 5 MB 空间。
4. 点击开始合并，等待成功；保留自动生成的 .original.日期_时间_序号.bak。
5. Disc 2 使用自己的完整 VIV 重复操作；将各盘文件放回对应目录，游戏语言保持 English。
6. 恢复时关闭游戏，将修改版另行改名，再将同盘对应备份改回 bigfile0.viv。
